# archives/ — original downloaded bundles

The `.tar.gz` archives exactly as downloaded from the 2014 CS365 project
submission page (see [`../README.md`](../README.md) for the source URL):

- `corpus.tar.gz` — the full raw text corpus.
- `training.tar.gz` — the training split used by the original project.
- `test.tar.gz` — the test split used by the original project.

These are archival copies of the original download, kept for provenance.
The version of this data actually used by the current code has already been
extracted into [`data/raw/`](../../data/README.md) and
[`data/snippets_2014/`](../../data/README.md).
