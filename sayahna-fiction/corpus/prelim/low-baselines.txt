LOW BASELINES — what survives when the shortcuts are removed
============================================================================

text version: corpus/texts
corpus: 114 works, 12 authors
works per author: min 5, median 8, max 19
chance level (macro-F1 of random guessing) ≈ 0.083

Whole works are held out in every run, so there is no chunk leakage.
The question here is different: WHICH SIGNAL is the model using?

============================================================================
  labels shuffled (run 1)                      5-fold  macro-F1=0.033  acc=0.044

     strong clusters. Far above (say >2x chance) means the pipeline leaks.

2. REMOVE NAMED ENTITIES AND PRIVATE VOCABULARY
============================================================================
  masked 133,446 of 153,977 token types (87%) that only ever appear in one author
  those types are 39.5% of all running text — the number that matters,
  since most type inventory is hapax and carries little of the text
  single-author tokens masked                  5-fold  macro-F1=0.927  acc=0.956  
  -> DROP 0.963 -> 0.927  (-0.036)
     A large drop means the score was mostly names and private topics.

  masked 146,875 token types occurring in fewer than 5 documents
  rare tokens (df<5) masked                    5-fold  macro-F1=0.962  acc=0.974  

============================================================================
3. CONTENT-FREE STYLOMETRY — only the commonest words survive
============================================================================
  Malayalam has no standard stopword list, so corpus frequency stands in.
  top-100 tokens only (rest masked)            5-fold  macro-F1=0.780  acc=0.825  vocab=100
  top-300 tokens only (rest masked)            5-fold  macro-F1=0.867  acc=0.904  vocab=300
  -> 0.867 against 0.963 on full text. If this stays high,
     the signal is genuinely stylistic rather than topical.
  top-1000 tokens only (rest masked)           5-fold  macro-F1=0.914  acc=0.947  vocab=1000

============================================================================
4. DESTROY WORD ORDER — keep vocabulary, lose syntax and phrasing
============================================================================
  NOTE: char_wb n-grams never cross a word boundary, so shuffling words
  cannot change them — that comparison is vacuous. This run therefore uses
  analyzer='char', which DOES span boundaries and so can see phrasing.

  char (spans boundaries), intact              5-fold  macro-F1=0.963  acc=0.974  
  char (spans boundaries), shuffled            5-fold  macro-F1=0.963  acc=0.974  
  -> 0.963 -> 0.963  (+0.000)
     A small drop means cross-word phrasing carries little of the signal;
     the model is working from within-word evidence (morphology, spelling).

  char_wb (within words only), intact          5-fold  macro-F1=0.963  acc=0.974  
  -> within-word only 0.963 vs boundary-spanning 0.963: +0.000

============================================================================
HOW TO READ THIS
============================================================================
  Sections 2 and 4 are the important ones.
  If masking single-author tokens barely moves the score, and shuffling
  word order barely moves it either, then the model is doing topic
  classification and the honest number is the one in section 6.
  If the score survives both, you have real stylistic signal and that
  is a result worth writing up.

  Report section 1 AND section 6 in any paper. Reporting only section 1
  is what the existing Indic AA literature does, and it is why its
  numbers are not comparable to anything.
